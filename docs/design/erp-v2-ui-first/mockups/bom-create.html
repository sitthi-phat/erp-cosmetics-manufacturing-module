✓ รหัสนี้ใช้ได้ (ยังไม่มีในระบบ)
1 BOM = 1 FG (1:1 · แชร์รหัสเดียวกัน · D11 v2) · รหัส = ผู้ใช้พิมพ์เองตอนสร้าง + ต้องไม่ซ้ำ · ล็อกหลังสร้าง (create-only-lock) แก้ไม่ได้ เพื่อคง reference (FG stock/PO/SO/QT/Batch/trace) ไม่แตก · กติกาเดียวกับรหัส RM · FG ค้นได้ทั้งชื่อและรหัสในคลัง
🏭 OEM — รับจ้างผลิต (made-to-order)🧴 FG — แบรนด์ตัวเอง (เก็บสต็อก/วางแผน)
1 BOM = 1 FG (auto · D11) · OEM = ผลิตตามสั่ง ไม่ต้องตั้งค่าวางแผน · FG = Own-Brand ที่เก็บสต็อก → กรอกค่าวางแผน (Supply Planning) ด้านล่าง
