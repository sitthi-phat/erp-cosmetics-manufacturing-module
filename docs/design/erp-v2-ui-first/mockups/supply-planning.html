FG อยู่สถานะ Low (cover < Target) — แจ้งเตือนแล้ว · ต้องสั่งผลิต:
Low FG-101 · เอสเซนส์ ไบรท์ เซรั่ม — ควรผลิต 1,500 หน่วย (ceil 3 แบตช์ × 500) 🏭 สั่งผลิต 1,500 →
แจ้งเตือนเชิงรุก (ไม่ใช่ on-read): ยิง real-time ทันทีที่ FG พลิกเข้า Low + สรุปรายวัน ~06:00 (J8 digest) — ส่งเข้า Notification panel 🔔 ให้ผู้มีสิทธิ์ Read Supply Planning (deep-link มาการ์ด FG นี้ / หน้าสร้าง SO ผลิตเก็บสต็อกที่ prefill Suggested) · แนบ Suggested เสมอ (platform.md §FG→Low · §5.1)
ℹ️
ป้ายสถานะ (D5): Low cover < Target · OK Target ≤ cover ≤ 2×Target · Overstock cover > 2×Target · Available = FG On Hand + In Production · Suggested = ปัดขึ้น (ceil) ให้เต็มทวีคูณ Batch Size จนถึง Target (D6)
🔒
FG ที่สูตร (BOM) ปิดใช้งาน (Inactive) จะถูกกันออกจากหน้านี้ — ไม่คำนวณ Suggested · ไม่มีปุ่ม "สั่งผลิต" · ไม่ยิงแจ้งเตือน Low (ผลิตเติมสูตรที่ปิดไปแล้วไม่ได้) · งานผลิต/Batch ที่วิ่งอยู่แล้วเดินต่อจนจบได้ตามปกติ (bom.md §5c)
