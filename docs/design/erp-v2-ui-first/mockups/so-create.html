สร้างใบสั่งขาย (Own-Brand)

สาย Own-Brand · 🧾 เลขที่: (ระบบออกให้เมื่อบันทึก) · ไม่มีใบเสนอราคา (Quotation) · เลือกโหมดตาม D2 — (ก) ขายจากสต็อก = ต้องเลือกลูกค้า / (ข) ผลิตเก็บสต็อก = ไม่ต้องเลือกลูกค้า
← ย้อนกลับ
🧴 (ก) ขายจากสต็อก — เลือกลูกค้า 🏭 (ข) ผลิตเก็บสต็อก — ไม่เลือกลูกค้า

ขายจากสต็อก — บังคับเลือกลูกค้า (D2-a) · ค้นด้วยเบอร์/บริษัท/ผู้ติดต่อ · modal ไม่ทำให้ฟอร์มหาย (G3/G4)
🚫
HARD block (เฉพาะโหมด ก ที่มีลูกค้า): ลูกค้าสถานะ ปิดใช้งาน (Disabled) หรือ บัญชีดำ (Blacklist) — ค้นเจอ+เห็นสถานะได้ แต่ เลือกไม่ได้ · ถ้าหลุดเข้ามา ระบบบล็อกตอนยืนยัน: "ลูกค้าสถานะ Disabled/Blacklist — เปิดใบสั่งขายไม่ได้" · โหมด (ข) ไม่เลือกลูกค้า → ไม่เกี่ยวกับ block นี้
🏭
ผลิตเก็บสต็อก — ไม่ต้องเลือกลูกค้า (D2-b). เมื่อยืนยัน ระบบสร้าง PRD ไม่ผูกลูกค้า (เหมือนปุ่ม "สั่งผลิต" ใน Supply Planning) · FG เข้าคลังตอน QC ผ่าน (D12) แล้วค่อยขายผ่านโหมด (ก) ภายหลัง
