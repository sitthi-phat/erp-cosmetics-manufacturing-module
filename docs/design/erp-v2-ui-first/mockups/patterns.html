รูปแบบมาตรฐานทั้งระบบ (Global Patterns)

หน้ารวมรูปแบบที่ใช้ซ้ำทุกหน้า: ป็อปอัปยืนยันก่อนบันทึก · หน้า error (403/404/500) · สถานะว่าง (empty state) · และองค์ประกอบ shell (กระดิ่ง/snackbar/แบนเนอร์ session/ปิดบัญชีของฉัน) ที่เห็นตัวอย่างจริงได้ที่ แดชบอร์ด →

P-1 · ป็อปอัปยืนยันก่อนบันทึก (Global submit-confirm)

ทุก action ที่เปลี่ยนข้อมูลต้องยืนยันก่อนเสมอ · ยกเลิก = ไม่มีอะไรเปลี่ยน (ไม่กินเลขเอกสาร ไม่บันทึก audit) · อ้าง non-functional.md §9.1

ต้องยืนยัน / ไม่ต้องยืนยัน
  • ต้อง ✔
    สร้าง · บันทึก/แก้ไข · เปลี่ยนสถานะ · ลบ · void · ยกเลิก · อนุมัติ · ตั้งค่า (VAT/บริษัท/role)
  • ไม่ ✕
    ค้นหา · เปิดดู/อ่าน · กรอง (filter) · เปลี่ยนหน้า (pagination) — ทำได้ทันที ไม่มีป็อปอัป
โครงป็อปอัป: (1) หัวเรื่องบอกการกระทำ · (2) สรุปสิ่งที่จะเปลี่ยน (เอกสาร/ค่า/สถานะ เดิม→ใหม่; ถ้าออกเลขตอนบันทึก = แจ้งว่าเลขจะออกเมื่อยืนยัน) · (3) ปุ่ม ยืนยัน + ยกเลิก
ลองใช้งานจริง

คลิกเพื่อดูป็อปอัปยืนยัน 3 แบบ — สังเกตว่าสรุปการเปลี่ยนแปลงชัดเจน และมีปุ่มยกเลิกเสมอ

💡 snackbar ยืนยันผลสำเร็จจะเด้งมุมขวาล่าง (คนละอย่างกับป็อปอัป — เป็นการแจ้งหลังทำสำเร็จ)

P-2 · หน้า Error ที่เป็นมิตร (403 / 404 / 500)

ข้อความไทยเข้าใจง่าย + ทางออกกลับเสมอ · ไม่โชว์ stack trace / enum ดิบ / error ระบบ · อ้าง non-functional.md §9

403

ไม่มีสิทธิ์เข้าถึง

บัญชีของคุณยังไม่มีสิทธิ์ดูหน้านี้ หากต้องการเข้าถึง กรุณาติดต่อผู้ดูแลระบบ

← กลับแดชบอร์ด
404

ไม่พบหน้าที่ต้องการ

หน้าหรือเอกสารที่คุณเปิดอาจถูกย้าย ลบ หรือลิงก์ไม่ถูกต้อง

← กลับแดชบอร์ด
500

ระบบขัดข้องชั่วคราว

เกิดข้อผิดพลาดที่ฝั่งระบบ กรุณาลองใหม่อีกครั้ง หากยังพบปัญหา กรุณาแจ้งผู้ดูแลระบบ

P-2 · สถานะว่าง (Empty State)

ทุก list / ผลค้นหา ที่ไม่มีข้อมูล = ข้อความเป็นมิตร + ปุ่มถัดไป (ถ้ามี) — ไม่ใช่หน้าเปล่าหรือ error

🔍

ไม่พบผลการค้นหา

ลองปรับคำค้นหรือช่วงวันที่ใหม่อีกครั้ง

📄

ยังไม่มีรายการ

ยังไม่มีใบสั่งซื้อในระบบ เริ่มต้นด้วยการเปิดใบแรก

➕ เปิด PO ใหม่
🔔

ไม่มีการแจ้งเตือน

รายการที่ปิดไปแล้วยังดูย้อนหลังได้ที่ "ดูทั้งหมด"

ดูทั้งหมด

O · องค์ประกอบ Shell (กระดิ่ง 4 ประเภท · snackbar+สั่น · session banner · ปิดบัญชีของฉัน)

ดูตัวอย่างที่เคลื่อนไหวจริงได้ที่ แดชบอร์ด (มีปุ่มรีวิวมุมซ้ายล่าง) · หน้าประวัติแจ้งเตือน = การแจ้งเตือนทั้งหมด

กระดิ่งแจ้งเตือน (redesign)
  • 🔴
    Badge สูงสุด "9+"
  • ❌
    ปิดราย item (✕) = เอาออกจากกระดิ่งของ user นั้น — ไม่ใช่ "อ่านแล้ว" (dismiss ≠ read; เป็นรายบุคคล)
  • 🧹
    ปุ่ม "ปิดทั้งหมด" = ล้างกระดิ่งของตัวเอง (badge → 0)
  • 📜
    ลิงก์ "ดูทั้งหมด" → หน้าประวัติ 20/หน้า (ประวัติไม่หายแม้ปิดจากกระดิ่ง)
  • 🗂️
    จัดกลุ่ม 4 ประเภท: 1 งานส่งต่อข้ามแผนก 2 ความเสี่ยงสต็อก/ผลิต 3 การเงิน 4 วงจรลูกค้า
  • 📳
    มี notification ใหม่ → snackbar เด้ง + กระดิ่งสั่น (shake)
Session / บัญชี
  • ⏳
    แบนเนอร์เตือน session โผล่ล่วงหน้า 10 นาที "อีก 10 นาทีจะออกจากระบบ" ก่อนตัดเวลา 06:00 (A2)
  • 🚫
    เมนูผู้ใช้มี "ปิดบัญชีของฉัน" → ยืนยัน → ตัด session + login ไม่ได้จนกว่า Admin เปิดคืน (A11)
  • 🔑
    "ลืมรหัสผ่าน" บน login → reset-password (ลิงก์ใช้ครั้งเดียว 3 วัน, ไม่เปิดเผยว่ามีบัญชีหรือไม่)
▶ ดู shell จริง
